AIのAPIとは？チャット画面と何が違うの？

AIのAPIとは、AIを、人が画面で操作するのではなく、プログラムから呼び出すための窓口です。

APIは「Application Programming Interface」の略です。
ソフト同士がやり取りするための、決まった受付口のようなものだと考えてください。

お店にたとえると…

チャット画面とAPIの違いは、お店での「注文のしかた」の違いにたとえるとわかりやすくなります。

チャット画面は、店頭で店員さんと話しながら注文する方法です。
その場で相談しながら決められる反面、注文するたびに人が行く必要があります。

APIは、決まった書式の注文票を送る方法です。
書式さえ守れば、システムが自動で何百枚でも注文を送れるので、同じ作業の自動化に向いています。

チャット画面
（ChatGPT・Gemini・Claudeのアプリ）		API
使う人人が直接入力する自社のサイト・システムが自動で呼び出す
料金月額の定額（無料プランあり）使った量に応じた従量課金
向いている使い方調べもの・文章の相談同じ作業の自動化・自社サービスへの組み込み
多くの人がつまずくポイント
ChatGPTやClaudeの有料プラン（月額）を払っていても、APIは使えません。
APIは開発者向けの管理画面で別に登録し、別に料金を支払う仕組みです。

中小企業での使いみちとしては、たとえば次のようなものがあります。

  • 問い合わせへの返信文の下書き
    フォームに届いた内容から、返信のたたき台を自動で作る
  • 商品・サービスの説明文づくり
    箇条書きのメモから、ネットショップ用の紹介文を作る
  • SNS投稿からブログ記事の下書き
    Instagramの投稿をもとに、読みものとして整えた記事のたたき台を作る

AIのAPIは無料で使える？無料枠の条件と注意点

条件つきで無料で使えます。
ただし「無料」はあくまで試すためのものです。入力した内容がAIの改善（学習）に使われることがある点に注意しましょう。

主要3社の状況は次のとおりです。

サービス無料で使える範囲注意点
Google Gemini API課金を有効にしなくても、軽量モデル（Flash・Flash-Lite系）を回数制限つきで利用できる。上位のProモデルは無料枠の対象外無料枠で送った内容は、Googleのサービス改善に使われる（有料枠では使われない）
OpenAI API誰でも使える常設の無料枠はない。入力内容の共有（学習への利用）に同意すると、1日あたり一定量が無料になる仕組みがある無料分は入力内容が学習に使われる前提。機密情報には不向き
Claude API（Anthropic）新規登録時に、動作確認用の少額の無料クレジットがもらえる継続的な無料枠はない。使い続けるにはクレジットの購入が必要。
入力内容は、フィードバックを送るなど本人が許可しない限り学習に使われない

※2026年9月25日時点の各社公式情報をもとにしています。無料枠の内容は変更されることがあります。
最新情報は各社の公式ページ（Gemini・OpenAI・Claude・Claudeの学習利用について）でご確認ください。

無料枠には、1分・1日あたりの回数制限があります。
上限を超えると一時的に使えなくなるので、「ちょっと試す」には十分でも、業務で毎日使うには心もとない量です。

そしてなにより、お客様の名前や連絡先、社外秘の資料を扱うなら、有料枠を使うのが基本です。
有料枠であれば、入力内容を学習に使わない条件で提供されているのが一般的です（契約前に各社の規約で確認してください）。

AIのAPIの料金はいくら？何で決まるの？

料金は「どのモデルを使うか」と「どれだけの文章をやり取りするか」で決まります。
1回あたりは数円程度のことが多く、気にすべきなのは回数です。

料金の単位は「トークン」

APIの料金は「トークン」という単位で数えます。
トークンは、AIが文章を細かく区切って数えるときの単位で、日本語ならおおよそ1文字＝1トークン前後が目安です（モデルや文章によって変わります）。

料金は、AIに渡す文章（入力）と、AIが書いた文章（出力）で別々にかかります。
出力のほうが高く設定されていて、料金表は「100万トークンあたり◯ドル」という書き方が一般的です。

Gemini 3.5 Flash-Lite：入力$0.30／出力$2.50		大量の分類・短い要約
中くらいClaude Haiku 4.5：入力$1／出力$5

料金やモデル名は頻繁に変わるため、利用前に必ず公式ページでご確認ください。

Linplanで実際にかかった費用

Linplanでは、Instagramの投稿をAI（Claude Sonnet 5）でブログ記事の下書きにする仕組みを使っています。
投稿の文章と写真を渡すと、見出しや構成を整えた記事のたたき台が返ってくるものです。

1記事あたりのやり取りは、およそ入力5,000トークン・出力4,000トークン。
費用は見積もりで約7〜8円（1ドル＝150円で換算）です。

人が一から書く手間を考えると、下書きづくりのコストとしてはかなり小さいと言えます。

このように、1回あたりは数円〜数十円程度です。
問題になるのは、プログラムの不具合などで意図せず何千回も呼び出してしまったとき。次の3つをしておけば、想定外の請求はまず防げます。

  • 前払い制（クレジット購入）を選ぶ
    入れた金額以上は使われない
  • 自動チャージをオフにする
    残高がなくなったら止まるようにする
  • 管理画面で月の利用上限を設定する

OpenAI・Gemini・Claudeはどれがいい？得意なこと・苦手なこと

どれか1社が絶対的に優れているわけではありません。
何に使うかで向き・不向きが分かれます。一般的な傾向をまとめると次のとおりです。

Google GeminiOpenAI（GPT）Anthropic（Claude）
無料で試す◎ 課金設定なしの無料枠あり△ 学習利用に同意した場合のみ△ 登録時の少額クレジットのみ
料金の幅○ 軽量モデルは手ごろ◎ 非常に安い小型モデルから最上位まで幅広い○ 中価格帯が中心
入力内容の学習利用無料枠は使われる／有料枠は使われない無料トークン分は使われる／通常の有料利用は原則使われない本人が許可しない限り使われない
得意なこと画像・音声などの読み取り、Googleのサービスとの連携対応するツールや情報の多さ、機能の幅広さ長い日本語の文章作成、細かい指示を守る丁寧さ
苦手・注意点無料枠の内容が変わりやすい／無料枠は学習に使われるモデルの種類が多く、名前も変わりやすいため選びにくい継続的な無料枠がない

Geminiは、無料枠で気軽に試せるのが大きな魅力です。
写真や音声を読み取らせる使い方にも強いと言われることが多く、Googleのサービスと組み合わせやすい点も特長です。

OpenAI（GPT）は、利用者が多いぶん解説記事や対応ツールが豊富で、困ったときに情報を探しやすい傾向があります。
ごく安い小型モデルもあり、大量処理のコストを抑えやすいのも利点です。

Claudeは、長い日本語の文章を自然に書くことや、細かい指示に沿った出力が得意と評価されることが多いモデルです。
一方で、継続的な無料枠はありません。

Linplanが使っているAPIについて
Linplanでは記事の下書きづくりにClaudeを使っていますが、用途によってはGeminiやOpenAIのほうが向いています。
まずは同じ作業を2〜3社で試して、結果と費用を比べるのがおすすめです。

このほか、自分のパソコンやサーバーで動かせる、無料で公開されているAIモデルもあります。
ただし準備や運用に専門知識が必要で、性能面でも差があるため、中小企業の業務でいきなり選ぶには手間がかかります。

目的別：どのAIのAPIを選べばいい？

迷ったら、「やりたいこと」と「扱うデータの大事さ」から選ぶのが近道です。

やりたいこと選び方の目安
まずはタダで試したいGeminiの無料枠（ただし大事な情報は入れない）
日本語の文章をたくさん書かせたい中価格帯のモデル（Claude Sonnet・GPTの中位モデルなど）で比べてみる

AIのAPIの使い方は？始めるまでの3ステップ

使い始めるまでの流れは、どの会社でもほぼ同じです。
「アカウント作成 → APIキー発行 → 呼び出し」の3ステップで進みます。

  1. 開発者向けのアカウントを作る
    各社の開発者向け管理画面に登録します。チャット用のアカウントとは別物です。
  2. APIキーを発行する
    APIキーは、あなたの会社だと証明する合言葉のようなもの。
    知られると誰でもあなたの料金でAIを使えてしまうため、他人に見せない・サイトのHTMLに書かないことが鉄則です。
  3. プログラムから呼び出す
    決まった形式で「どのモデルに・何をしてほしいか」を送ると、AIの回答が返ってきます。

参考までに、ClaudeのAPIを呼び出す最小限の例です（読み飛ばしても大丈夫です）。
「このモデルで、この依頼文に、500トークン以内で答えて」という注文票を送っているだけ、とイメージしてください。

curl https://api.anthropic.com/v1/messages \
  -H "x-api-key: あなたのAPIキー" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{"model":"claude-sonnet-5","max_tokens":500,
       "messages":[{"role":"user","content":"船橋のパン屋の紹介文を100文字で"}]}'

安全に使うために、次の3点は必ず守りましょう。

  • APIキーはサーバー側や専用の保管場所に置く
    たとえばGitHubの「Secrets」のような、鍵を隠して保管する仕組みを使う
  • 利用上限を設定しておく
    万一のトラブルでも請求額が膨らまないようにする
  • AIの出力はそのまま公開せず、人が確認する
    事実の誤りや言い過ぎが混ざることがあるため

AI検索で見つけてもらうための準備については、「中小企業がAI検索時代に備えるためにできること」もあわせてどうぞ。

よくある質問

ChatGPTの有料プランに入っていればAPIも使えますか？

使えません。チャットの有料プランとAPIは別契約です。APIは開発者向けの管理画面で別に登録し、使った分の料金を支払います。

無料枠で商用利用しても大丈夫ですか？

各社の利用規約によって異なるため、使う前に規約を確認してください。また、無料枠では入力した内容がサービス改善に使われることがあるため、お客様の情報や社外秘は入れないのが安全です。

AIのAPIは月にいくらくらいかかりますか？

使い方次第ですが、文章の下書き程度であれば月に数百円〜数千円に収まることが多いです。管理画面で利用上限を設定しておけば、想定外の請求を防げます。

プログラミングができなくてもAIのAPIは使えますか？

ノーコードの自動化ツールを使えば、プログラムを書かずにAPIを利用する方法があります。自社のサイトやシステムに組み込みたい場合は、制作会社に相談するのが早道です。
